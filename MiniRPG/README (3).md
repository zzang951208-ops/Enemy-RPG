# 새벽빛 전설 (Dawnlight Legend)

Unity로 만든 쿼터뷰 액션 RPG입니다. NPC, 퀘스트, 상점, 보스전이 있고, 도박사 NPC의 천막에서 슬롯머신, 주사위, 블랙잭, 룰렛을 즐길 수 있습니다.

**모든 그래픽, UI, 효과음을 C# 코드로 생성**하기 때문에 외부 에셋이 필요 없습니다. 스크립트 폴더만 넣고 Play를 누르면 바로 실행됩니다.

---

## 1. 실행 방법

> Unity 게임은 **Unity 에디터에서 열거나**, 에디터로 **실행 파일(.exe)을 빌드**해야 실행됩니다. 압축 파일 안의 `.cs` 파일을 직접 더블클릭해서는 실행되지 않습니다.

### 방법 A. 프로젝트 폴더를 그대로 열기 (가장 간단)

1. 압축을 풉니다. 이때 경로에 한글이나 공백이 없는 곳이 좋습니다. (예: `C:\UnityProjects\MiniRPG`)
2. **Unity Hub → Projects → Add(추가) → Add project from disk**를 누르고, 압축을 푼 `MiniRPG` 폴더를 선택합니다.
   - `Assets`, `Packages`, `ProjectSettings`가 들어 있는 폴더입니다.
3. 에디터 버전을 고르라는 창이 나오면, 설치된 버전 중 **2021.3 이상**을 고릅니다. 업그레이드 확인 창이 뜨면 계속 진행합니다.
4. 프로젝트가 열리면 "설치 완료" 창이 뜹니다. **[지금 게임 시작]**을 누르면 바로 실행됩니다.
   - 창을 닫았다면 상단 메뉴 **MiniRPG → ▶ 게임 시작**을 누르세요.

### 방법 B. 새 프로젝트에 넣기

1. Unity Hub에서 **3D (Built-in)** 또는 **3D (URP)** 템플릿으로 새 프로젝트를 만듭니다.
2. 압축 안의 `Assets/MiniRPG` 폴더를 새 프로젝트의 `Assets` 폴더에 복사합니다.
3. 컴파일이 끝나면 상단 메뉴 **MiniRPG → ▶ 게임 시작**을 누릅니다.
   - 게임 씬(`Assets/MiniRPG/Scenes/Main.unity`)이 자동으로 만들어지고, 빌드 목록에도 등록됩니다.

### 실행 파일(.exe) 만들기 (제출용)

1. 상단 메뉴 **MiniRPG → 실행 파일 만들기 (현재 OS용)**를 누릅니다.
2. 빌드가 끝나면 프로젝트 폴더의 `Builds/Windows/` 폴더가 열립니다.
3. `DawnlightLegend.exe`를 더블클릭하면 게임이 실행됩니다.
   - **제출할 때는 `Builds/Windows` 폴더 전체를 압축**하세요.
   - exe 파일 옆의 `DawnlightLegend_Data` 폴더와 `UnityPlayer.dll`이 함께 있어야 실행됩니다.

### 문제가 생기면

| 증상 | 원인과 해결 |
|---|---|
| 상단에 **MiniRPG 메뉴가 없음** / Play를 눌러도 아무 일도 없음 | 스크립트 컴파일 오류가 있으면 메뉴와 게임이 모두 동작하지 않습니다. Console 창(`Ctrl+Shift+C`)의 빨간 `error CS...` 줄을 확인하세요. 기존 프로젝트의 다른 스크립트와 충돌하는 경우가 많으니 **방법 A**나 새 프로젝트로 실행하세요. |
| 게임 화면 위쪽에 **빨간 오류 창**이 뜸 | 실행 중에 오류가 난 것입니다. 창의 첫 줄을 그대로 복사해서 알려주시면 바로 고칠 수 있습니다. (F1로 숨기기) |
| 버튼이 클릭되지 않음 | Unity 6의 새 Input System 설정에서 생기던 문제이며, 이번 버전에서 수정했습니다. |
| 빌드 실패: 모듈 관련 오류 | Unity Hub → Installs → 사용 중인 버전의 톱니바퀴 → **Add modules**에서 `Windows Build Support (Mono)`를 설치하세요. |
| 한글이 □로 보이거나 글자가 안 보임 | 운영체제의 한글 폰트를 사용합니다. Windows(맑은 고딕)나 macOS에서 실행하세요. |
| 분홍색(마젠타) 물체가 보임 | HDRP 프로젝트는 지원하지 않습니다. Built-in 또는 URP 템플릿을 사용하세요. |

> **입력 시스템:** 기존 Input Manager, 새 Input System, Both 설정 모두에서 자동으로 맞춰 동작합니다.
> **저장 데이터:** `PlayerPrefs`에 저장되며, 메뉴 **MiniRPG → 저장 데이터 삭제**로 지울 수 있습니다.
> **주의:** 게임은 프로젝트의 모든 씬에서 자동으로 실행됩니다. 이 게임 전용 프로젝트에서 사용하세요.

## 3. 게임 기획 요약

### 3-1. 개요
- **장르:** 쿼터뷰 액션 RPG
- **플레이 시간:** 약 50~80분 (1부 엔딩 + 후반부 진 엔딩)
- **스토리:**
  - **1부:** 고블린 왕 '그락'이 나타난 뒤 새벽빛 마을 주변에 몬스터가 늘어났습니다. 떠돌이 모험가인 플레이어가 촌장의 의뢰를 받아 초원, 숲, 고블린 야영지를 지나 북쪽 제단의 그락을 쓰러뜨립니다.
  - **2부:** 그락의 힘이 고대 봉인을 지탱하고 있었다는 사실이 드러납니다. 봉인이 풀리자 '잊혀진 폐허'의 망자들이 깨어나고, 학자 엘라라와 함께 망령 군주 모르가스에 맞서 진 엔딩에 도달합니다.

### 3-2. 월드 구성 (남쪽에서 북쪽으로 진행)

| 지역 | 권장 레벨 | 내용 |
|---|---|---|
| 새벽빛 마을 | 안전 지대 | NPC 8명, 상점, 여관, 도박 천막이 있고 HP/MP가 빠르게 회복됩니다 |
| 슬라임 초원 | 1~3 | 슬라임이 나오고, 달빛 약초를 채집할 수 있습니다 |
| 속삭이는 숲 | 3~6 | 무리 지어 다니는 빠른 늑대가 나옵니다 |
| 고블린 야영지 | 6~9 | 목책 안에 강한 고블린 전사가 있습니다 |
| 고블린 왕의 제단 | 9+ | 보스 **고블린 왕 그락**이 있습니다 |
| 잊혀진 폐허 | 11+ | 그락을 처치하면 봉인의 문이 열립니다. 묘지, 무너진 신전, 유령불 사이로 해골 병사와 망령이 떠돌고, 가장 깊은 의식장에 최종 보스 **망령 군주 모르가스**가 있습니다 |

### 3-3. 전투 시스템
- **기본 공격:** 전방 부채꼴 범위를 공격합니다. 12% 확률로 치명타(1.8배)가 터집니다.
- **회전베기:** MP를 써서 주변 적을 모두 공격하는 광역기입니다.
- **대시:** 짧은 무적 시간이 있는 회피기입니다.
- **몬스터 AI:** 배회, 추적, 공격, 복귀 상태를 오가는 상태 머신입니다. 일정 거리 이상 끌려가면 제자리로 돌아가고, 마을 안으로는 들어오지 않습니다.
- **몬스터 7종:** 슬라임, 회색 늑대, 고블린 전사, 해골 병사, 울부짖는 망령(원거리형: 거리를 벌리며 구체 발사), 보스 2종
- **보스 1 — 고블린 왕 그락:**
  - 바닥에 붉은 원으로 예고한 뒤 내려찍는 범위 공격을 합니다.
  - 체력이 35% 이하로 떨어지면 분노 상태가 되어 공격과 이동이 빨라집니다.
- **보스 2 — 망령 군주 모르가스:**
  - 사방으로 구체 12개를 흩뿌리는 탄막 공격을 합니다. 대시 무적으로 뚫고 지나갈 수 있습니다.
  - 플레이어 발밑에 보라색 원을 만든 뒤 폭발시킵니다.
  - 체력 70%와 35%에서 해골 병사를 소환합니다.
  - 분노하면 탄막이 두 번 발사되고 어둠의 원이 세 개로 늘어납니다.
- **성장:**
  - 레벨이 오르면 HP, MP, 공격력, 방어력이 오르고 체력이 완전히 회복됩니다.
  - 무기 5종과 방어구 5종이 있습니다. 그락을 처치하면 대장간에 룬 장비가, 약초 가게에 엘릭서가 새로 입고됩니다.
- **사망 시:** 마을에서 부활하며, 치료비로 소지금의 10%를 잃습니다.

### 3-4. NPC와 퀘스트

| NPC | 역할 |
|---|---|
| 촌장 에드릭 | 메인 퀘스트 4개 (슬라임 → 늑대 → 고블린 → 고블린 왕) |
| 대장장이 브론 | 무기·방어구 상점. 서브 퀘스트 '늑대 가죽'의 보상은 가죽 갑옷 |
| 약초상 리나 | 포션 상점. 서브 퀘스트 '달빛 약초 채집' |
| '럭키' 잭 | 도박 천막. 서브 퀘스트 '잃어버린 행운'을 완료하면 하이롤러 테이블이 열림 |
| 여관주인 마사 | 휴식(30G), 저장, 게임 팁이 담긴 소문 |
| 경비병 토르 | 레벨에 맞는 사냥터와 몬스터 정보 안내. 서브 퀘스트 '야영지 정찰 보고'의 보상은 사슬 갑옷 |
| 꼬마 피피 | 마을을 돌아다니며 게임 힌트를 줌. 서브 퀘스트 '피피의 보물'(숲에서 잃어버린 인형 찾기) |
| 학자 엘라라 | 봉인과 폐허의 세계관 설명. 후반 메인 퀘스트 2개와 서브 퀘스트 '망령 연구' |

- **퀘스트 12개:** 메인 6개(1부 4개, 2부 2개)와 서브 6개입니다.
- 퀘스트는 `잠김 → 수락 가능(!) → 진행 중 → 보고 가능(?) → 완료` 순서로 진행됩니다.
- NPC 머리 위 아이콘과 화면의 퀘스트 추적창으로 진행 상황을 보여줍니다.

### 3-5. 도박 시스템: 럭키 잭의 행운 천막

게임 안의 골드만 사용하는 미니게임 4종입니다. 게임 경제의 **골드 소모처**이자 **위험과 보상**을 체험하는 요소로 설계했습니다.

| 게임 | 규칙 | 기대 환급률 |
|---|---|---|
| 슬롯머신 | 가중치가 다른 그림 6종. 같은 그림 3개면 5~50배, 2개면 1.3배 | 약 91% |
| 주사위 하이로우 | 주사위 2개의 합을 예측. 낮음·높음은 2.2배, 7은 5.5배 | 약 92% |
| 블랙잭 | 딜러는 17 이상에서 멈춤. 히트, 스탠드, 더블다운 가능. 블랙잭은 2.5배 | 약 99% (최적 전략 시) |
| 룰렛 | 유럽식 싱글 제로(0~36). 빨강·검정·홀짝·절반 2배, 12칸 묶음 3배, 숫자 하나 36배 | 약 97.3% |

- **베팅액:** 10, 50, 100, 500G 중에서 고릅니다. 하이롤러 테이블이 열리면 1000G와 5000G가 추가됩니다.
- **특별 보상:** 100G 이상 걸고 슬롯에서 7-7-7이 나오면 전설 무기 '용살자의 검'을 한 번 얻습니다.
- **연출:** 릴 회전, 앞의 두 릴이 맞으면 마지막 릴이 더 오래 도는 긴장 연출, 주사위 굴림, 카드 딜링, 실제 유럽식 숫자 배치를 따르는 룰렛 휠 회전과 공이 안쪽으로 떨어지는 연출, 큰 당첨 시 코인이 쏟아지는 효과가 있습니다.
- **책임감 있는 설계:**
  - 도박사 NPC가 "장기적으로는 하우스가 이긴다"며 실제 확률을 공개합니다.
  - 순손실이 1000G를 넘으면 NPC 대사와 게임 창에서 쉬어가라고 경고합니다.
  - 전적(판수, 승리, 총 베팅, 순이익)을 기록해서 보여줍니다.
  - 도박이 없어도 사냥과 퀘스트만으로 게임을 클리어할 수 있도록 경제를 조정했습니다.

### 3-6. UI / UX
- **HUD:** HP, MP, 경험치 바(피격 시 잔상 효과), 원형 미니맵, 지역 이름, 퀘스트 추적창, 쿨다운이 표시되는 액션바, 보스 체력바
- **창:** 대화창(타이핑 효과, 선택지), 상점(구매·판매 탭, 현재 장비와 비교, 더 좋은 장비 자동 장착), 인벤토리(능력치, 장착, 사용), 퀘스트 일지
- **메뉴:** 타이틀, 일시정지, 조작법, 사망, 엔딩 화면(1부 엔딩과 진 엔딩, 플레이 기록 통계)
- **알림:** 데미지 숫자, 토스트 알림, 지역 진입 배너, 레벨업 연출, 화면 흔들림

## 4. 코드 구조

```
Assets/MiniRPG/Scripts
├─ Core      GameManager(부팅·흐름·저장), GameInput(입력 추상화), SoundFX(절차적 사운드),
│            Fx(파티클·데미지 텍스트), CameraFollow, MinimapCam, ErrorReporter(화면 오류 표시)
├─ Data      GameData(아이템·몬스터 DB), Quests(퀘스트 정의·상태 관리)
├─ Player    PlayerController(이동·전투), PlayerData(인벤토리·능력치)
├─ Enemies   Enemy(AI 상태 머신·보스 패턴·원거리 AI), SpawnZone(리스폰), Projectile(투사체)
├─ NPC       NPC(모델·이름표·배회), NpcDialogues(대화 트리)
├─ World     WorldBuilder(맵 절차 생성·봉인의 문), Herb(채집물), QuestPickup(퀘스트 전용 아이템), Flicker, Bobber
├─ UI        UIManager, HUD, UIFactory(코드로 UI 생성), DialogueUI, ShopUI,
│            InventoryUI, QuestUI, MenuScreens, UIWindow
└─ Gambling  GambleUI(슬롯·주사위·블랙잭, GambleStats 전적), GambleUI.Roulette(룰렛, partial 클래스)

Assets/MiniRPG/Editor
└─ MiniRPGEditorTools   상단 [MiniRPG] 메뉴: 게임 시작, 씬 자동 생성, 실행 파일 빌드, 저장 삭제
```

**설계 포인트**
- **데이터와 표현 분리:** `ItemDB`, `EnemyDB`, `QuestManager` 같은 순수 C# 데이터 계층과 MonoBehaviour 표현 계층을 나눴습니다.
- **이벤트 기반 갱신:** `Inventory.Changed`, `PlayerStats.LeveledUp` 이벤트로 수집 퀘스트 진행도와 레벨업 연출을 처리합니다.
- **렌더 파이프라인 호환:** 기본 프리미티브의 머티리얼을 복제해서 쓰므로 Built-in과 URP 모두에서 동작합니다.
